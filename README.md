# 두드림 머니노트

두드림AI 강의 수입, 지출, 투자 내역을 한눈에 관리하기 위한 개인용 모바일 웹앱입니다.

- 라이브 주소: <https://dodream-money-note.ideacube-cod-4686.chatgpt-team.site/dodream/>
- GitHub 저장소: <https://github.com/LouiEll2033/dodreamai_moneynote>

## 1. 만든 목적

이 앱은 다음 문제를 해결하기 위해 만들었습니다.

- 강의별 수입을 따로 정리하기 번거로운 문제
- 월별 수입, 지출, 투자 흐름을 한 번에 보기 어려운 문제
- 입금 완료 여부를 계속 따로 체크해야 하는 문제
- 휴대폰과 컴퓨터에서 같은 내용을 함께 보기 어려운 문제

## 2. 현재 주요 기능

### 수입/지출/투자 관리

- 지출 기록
- 투자 기록
- 사업 / 개인 구분
- 월별 요약 카드
- 월별 분석
- CSV 내보내기

### 강의 수익 관리

- 강의 일정 기반 수익 그룹 관리
- 월별 강의 수익 합계 확인
- 입금 완료 체크
- 직접 추가 기능
- 항목 삭제 및 제외 처리
- 같은 강의명 그룹화

### 모바일 사용 최적화

- 휴대폰 한 화면에 맞는 레이아웃
- 월 이동과 월별 보기
- 상단 요약 카드 클릭 시 관련 내역 확인

## 3. 수익 분류 기준

현재 앱에서 주로 사용하는 분류는 아래와 같습니다.

- 여성인력개발센터
- 두정평생학습관
- 성환초등학교
- 월봉초등학교
- 특강

## 4. 데이터 저장 방식

처음에는 브라우저 `localStorage` 기반으로 시작했습니다.

이후 같은 주소로 접속한 기기끼리 같은 데이터를 볼 수 있도록 공유 저장 구조를 추가했습니다.

- 브라우저 로컬 저장
- 서버 공유 저장
- D1 기반 공용 상태 저장
- `/api/dodream-sync`를 통한 동기화

즉, 같은 앱 주소를 열면 휴대폰과 컴퓨터에서 같은 데이터를 볼 수 있도록 구성했습니다.

## 5. 최근 작업 정리

### 1) 모바일 레이아웃 정리

- 휴대폰에서 한 화면에 보기 쉽게 레이아웃 조정
- 요약 카드와 입력 화면 간격 정리

### 2) 기관/학교 항목 정리

- 기존 초등 방과후 항목을 실제 사용 항목으로 분리
- 성환초등학교, 월봉초등학교로 반영

### 3) 강의 일정 기반 수익 흐름 구성

- 강의 일정 목록을 월 기준으로 묶어 수익 그룹 생성
- 같은 강의명은 한 그룹으로 보이도록 정리
- 입금 완료 여부 체크 가능

### 4) 직접 추가 기능 보완

- 직접 추가한 항목이 월별 분석에 반영되도록 수정
- 금액 입력 제한을 1000원 단위에서 1원 단위로 변경
- 같은 직접 추가 항목은 다시 입력해서 금액/횟수/입금 상태를 수정할 수 있게 보완

### 5) 요약 카드 상세 보기

- 상단 요약 카드 클릭 시 관련 내역이 보이도록 수정

### 6) 기기 간 데이터 공유

- 휴대폰/컴퓨터에서 같은 내용을 보기 위해 공유 저장 구조 추가
- D1 테이블과 동기화 API 구성

### 7) 앱 시작 시 자동 동기화

- 앱을 열면 자동으로 강의 일정 데이터 동기화가 돌도록 수정

### 8) 삭제한 일정이 다시 나타나는 문제 해결

자동 동기화 때문에 삭제한 강의 일정이 다시 생기는 문제가 있었습니다.

이를 아래 방식으로 수정했습니다.

- 직접 추가한 항목은 실제 삭제
- 캘린더에서 들어온 항목은 삭제 대신 `제외` 처리
- 제외한 항목은 다음 자동 동기화 때 다시 가져오지 않음

즉, 사용자가 필요 없다고 판단한 일정은 계속 숨김 상태를 유지하도록 바뀌었습니다.
